# 巴适零食 · Bashi Snack Shop

中文单页宣传网页。原生 HTML、CSS、JavaScript，无第三方前端依赖，无需构建。

## 本地预览

安装 Node.js 后，在此目录运行：

```sh
node server.cjs
```

访问 http://127.0.0.1:4173 。使用 Ctrl+C 停止服务。可通过环境变量 PORT 更换端口。

## 修改内容

- `content.js`：统一维护门店地址、地图搜索关键词、城市、营业时间、电话、微信。空联系方式和营业时间自动隐藏。地图只搜索关键词，不指定坐标或铺位。
- `index.html`：品牌文案、品类介绍和页面结构。
- `styles.css`：基础颜色、版式和响应式规则。
- `experience.css`：手绘字形、全屏滚动舞台、移动端和减少动态效果的样式。
- `app.js`：地址配置渲染、复制反馈、地图链接、滚动展示。
- `motion.js`：随原生滚动进度鼓胀、撕开、散射的薯片袋，五幕品类切换及品牌段落。滚动不被拦截，提供跳过入口和品类选择按钮。
- `assets/`：生成的宣传图片、手绘位置示意、透明薯片素材、定制标题字形和站点图标。替换图片时请同步修改 HTML 中的替代文字。

地址依据用户提供的位置截图为“成都市双流区远大购物中心 A馆”，地图关键词为“成都远大购物中心-A馆”。定位截图为用户提供的参考资料，并非店铺精确铺位标记。没有推测楼层、电话、营业时间或经纬度。

图片为 AI 创意示意，具体商品和供应以门店实际情况为准；页面没有真实商品报价、库存、活动优惠或门店实拍。正文与按钮为 HTML 文字，生成的标题字形另有对应的可访问文本。

## 图片来源

图片由内置 imagegen 模型生成，项目使用 WebP 版本，透明素材保留 alpha。生成提示词记录在 `assets/prompts.md`。`map-v2.webp` 以用户提供的截图为参考重新生成手绘插画，保留主要相对位置，仅作示意，实际到店以地图导航为准。原始截图不在页面使用，也不纳入 Git。

主要中文标题和品牌字形为定制图片，保留对应可访问的 HTML 文本；正文与交互控件仍使用可选择的文字。首屏和收尾标语、品牌及到店标题使用同一手绘字形系列。

## 动效与兼容

薯片主场景通过原生滚动驱动：靠近、横向鼓胀、封口撕开、薯片沿固定轨迹散射，反向滚动可还原。CSS sticky 固定舞台，JavaScript 使用 passive scroll 和 requestAnimationFrame，仅在滚动或尺寸变化时更新。手机端减少粒子数。糖巧、坚果、糕点、小食和饮品以不同配色的全屏场景切换。

开启系统“减少动态效果”后，取消长滚动轨道与散射，五个品类全部以静态场景展示；关闭 JavaScript 时核心品牌、地址和地图链接仍可使用。

## Git 文件边界

应提交：HTML、CSS、JavaScript、`server.cjs`、文档、`.gitignore`、`.gitattributes`，以及页面实际引用的 WebP 和 SVG 素材。

不提交：`output/` 内的验收页、截图和制作脚本，原始参考地图 `assets/location.png`、已被替代的标题 `assets/headline-v2.webp`，缓存、依赖目录、本机编辑器设置、日志及 `.env` 凭据。生成图片的原 PNG 保留在 Codex 图片目录，不在项目仓库。

源码仓库：https://github.com/huangyangdaxuezha/bashishop 。源码推送与网站部署是独立步骤；部署前请确认门店资料和生成插画符合最终使用要求。

## 部署

可将 `index.html`、`styles.css`、`experience.css`、`content.js`、`app.js`、`motion.js` 和 Git 跟踪的 `assets/` 素材上传任意静态托管服务。`server.cjs` 仅供本地预览，不需要部署。`output/`、Git 元数据和参考原图不需要部署。此项目未自动发布。

剪贴板功能需 localhost 或 HTTPS 环境及浏览器授权；不可用时，页面显示手动复制提示。外部地图由高德提供。
